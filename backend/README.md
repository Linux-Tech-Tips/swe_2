## Prerequisties.

Have `gradle` installed.

For mac: `brew install gradle`
For fedora: `sudo dnf install gradle`

## How to run.
- Navigate towards `/tutorial-time`
- Run `gradle bootRun` 

## How to run case test.
- Navigate towards `/tutorial-time`
- Run `gradle test`

## Usage.
- Go towards: `localhost:8080/hello` to see a welcome message.
