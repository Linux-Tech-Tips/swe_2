\section{Challenges and their solutions}
\textbf{Database}: getting the database set up and running in the docker container was very difficult, but with time Ethan figured it out \\
\textbf{Connecting the frontend and backend}: understanding how to use fetch() to call apis correctly and set up the RestControllers properly to suit the fetch call configurations took a lot of trial and error and reading various documentation. Once we understood it for the first api calls, Martin wrote general react functions to make the process easier for each other instance. \\
\textbf{Infrastructure}: self-hosting all our infrastructure (i.e. the backend, frontend and CI components) was an additional challenge, but it wasn't too difficult to resolve (all components are up as of now) and has so far been a great learning experience. \\
\textbf{Unexpected Events}: various things have gotten in the way of people being able to complete their work.
We have been handling this by putting a focus on regular checkins and creating a healthy team environment for people to say that they aren't able to complete work as scheduled and the rest of the team figures out a way to still get the things done.
