\section{Challenges and their solutions}
Most of our challenges thus far have been technical in nature. \\

\textbf{Database}: getting the database set up and running in the docker container was very difficult, but with time Ethan figured it out \\
\textbf{Connecting the frontend and backend}: understanding how to use fetch() to call apis correctly and set up the RestControllers properly to suit the fetchcall configurations took a lot of trial and error and reading various documentation. Once we understood it for the first api calls, Martin wrote general react functions to make the process easier for each other instance. \\

Beyond technical issues, we've faced the regular problem of unexpected events getting in the way of people being able to complete their work.
We have been handling this by putting a focus on regular checkins via daily standups and creating a healthy team environment where people can mention that they aren't able to complete work as scheduled and the rest of the team figures out a way to still get the things done.
