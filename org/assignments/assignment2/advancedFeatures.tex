\section{Advanced Features}
The two main advanced features of this application are Tutorial Scheduling and Authentication.\\

1) Tutorial scheduling will be handled by scheduler objects, implementing the scheduling algorithm as outlined in the scheduling algorithm documentation. These schedulers will be instantiated as beans to be used in the codebase. In terms of the clean architecture, the scheduling will be in the use case layer.\\

2) Authentication will be handled via an external OAuth flow. The plan is to use Microsoft Authenticator, but if we can't get that working, we will implement a mock demo provider. In terms of the clean architecture, the authentication will be an external interface.
