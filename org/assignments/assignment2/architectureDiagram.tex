\section{Architecture Diagram}

The project is designed with the Clean architecture in mind.
The following layers are present:

\begin{itemize}
\item \textbf{Domain}:
    \begin{itemize}
    \item the entities, data value objects and aggregates the project consists of;
    \item more details available in section 4 (Domain Model).
    \end{itemize}
\item \textbf{Use Cases}:
    \begin{itemize}
    \item the behaviors/uses of the objects in the domain layer;
    \item mainly including tutorial scheduling, user registration, schedule creation/update and module and room creation/update.
    \end{itemize}
\item \textbf{Adapters/Interfaces}:
    \begin{itemize}
    \item the interfaces used to connect the domain to the infrastructure, as well as the API to connect the web UI to the backend;
    \item firstly, repository-based system to interact with an abstract data storage, to store users, modules and room details;
    \item secondly, a backend API with functions wrapping the aforementioned use cases.
    \end{itemize}
\item \textbf{UI + Infrastructure}:
    \begin{itemize}
    \item a double-ended external layer, consisting of the user-facing web UI and the actual server infrastructure;
    \end{itemize}
\end{itemize}
